# Native jobs

herdr-kata v2 executes Kata's portable jobs through herdr-core. See
[Jobs](jobs.md) for supported definitions, workflow steps and unsupported
features. Kata owns recurring issue children, notify delivery, schedules
and the Jobs/Runs interface. See [Install](install.md) to configure the
worker and [Operations](operations.md) to recover held runs.
